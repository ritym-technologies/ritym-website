1. EXOS-Station ESP32-S3 Hardware Pinout

The EXOS-Station pairs a Seeed XIAO ESP32-S3 dual-core microcontroller with an external u-blox NEO-M9N GNSS receiver.

XIAO ESP32-S3 Pin GPIO u-blox NEO-M9N Pin Function / Description
D7 GPIO44 TX Hardware UART RX (GPS data into ESP32 at 38,400 baud)
D6 GPIO43 RX Hardware UART TX (Configuration commands to u-blox)
GND GND GND Common ground reference
3V3 3V3 VCC Regulated 3.3V DC logic and power supply
D0 GPIO21 - User status LED (Heartbeat flash / Solid GPS 3D fix indicator)

2. Network & Telemetry Sockets

When operating in AP mode, the EXOS-Station establishes an unthrottled local telemetry access point:

  • Wi-Fi AP SSID: EXOS-GPS-XXXXX-WIFI (5-character unique hardware unit ID)
  • Local HTTP Dashboard: http://192.168.4.1 (Password protected)
  • Raw NMEA TCP Socket: 192.168.4.1:2000 (Streams NMEA 0183 sentences at up to 25Hz to up to 4 concurrent clients)
  • Bluetooth LE Peripheral: EXOS-GPS-XXXXX-BT with LE Secure Connections (UUID 00001101)
