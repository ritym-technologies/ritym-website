Installation in 3 Steps

🪟 Windows

1

Download & Extract

Download the ZIP from GitHub Releases. Extract to any folder (e.g. C:\ExosGPS).

2

Launch GPS Station

Double-click run_windows_bridge.bat — it auto-installs Python dependencies via uv.

3

Connect GPS Device

Click Rescan Ports, select your GPS device from the dropdown, and click Connect Station.

🤖 Android

1

Install APK

Download the APK file and install it. Allow installation from unknown sources if prompted.

2

Grant Permissions

Allow Location, Bluetooth, and Notification permissions when prompted at first launch.

3

Select Mode & Connect

Choose Transmitter or Receiver tab, select a Bluetooth device, and tap Start.
