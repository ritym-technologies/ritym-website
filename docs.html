Quick Start Guide (Phone to PC)

Follow these 4 steps to stream your phone's GPS to a Windows computer in under 3 minutes:

1

Pair Phone & PC via Bluetooth

Go to Windows Settings → Bluetooth & Devices → Add Device. Pair your Android phone with Windows. Confirm the 6-digit PIN on both screens.

2

Launch Android App in Transmitter Mode

Open EXOS GPS on your phone. Ensure the TRANSMITTER tab is selected, pick your paired PC from the list, and tap START TRANSMITTING.

3

Launch Windows EXOS GPS Station

Run run_windows_bridge.bat on your PC. The application will scan available serial ports automatically.

4

Select Port & Connect

Select the entry labeled Mobile GPS - Bluetooth - [Phone Name] (Recommended) from the dropdown, then click Connect Station.

Resilient Connection Handler

Windows Bluetooth COM ports can freeze if a device disconnects unexpectedly. EXOS GPS Station wraps port connection calls in an isolated process. If a port does not respond within 15 seconds, the attempt is safely cancelled and a Cancel Connection countdown button appears — ensuring the desktop UI never freezes.

USB Serial Receiver Setup

To connect a hardware USB GPS puck (u-blox, FTDI, Prolific PL2303, SiRF):

  1. Plug the USB receiver into a USB port on your Windows PC.
  2. Open Windows Device Manager → Ports (COM & LPT) to verify the assigned COM port (e.g. COM3).
  3. In EXOS GPS Station, click Rescan Ports and select the entry matching your USB serial hardware.
  4. Baud rate is configured automatically (default: 9600 for standard NMEA receivers).

Android System Mock Location

Allow Google Maps, Waze, Navionics, and all installed Android system apps to receive live GPS coordinates relayed from another phone or PC:

1

Enable Developer Options

Go to Android Settings → About Phone → Tap Build Number 7 times until Developer Options is enabled.

2

Select Mock Location App

Go to Android Settings → System → Developer Options → Select mock location app → Choose Exos GPS Solutions.

3

Start Receiver Mode

Open EXOS GPS, select the RECEIVER tab, and start receiving. The app banner will display MOCK LOCATION: ACTIVE 🟢.

Troubleshooting Guide

Bluetooth COM port stays on "Connecting..."

Click Cancel Connection on the countdown button. In Windows Settings, unpair and re-pair the phone. Ensure the phone is actively broadcasting in Transmitter mode before connecting.

No GPS coordinates visible in log ("Awaiting Fix...")

Ensure the transmitting phone or receiver has a clear line of sight to the sky. GPS receivers indoors may take several minutes to acquire satellite locks (GGA fix quality = 0 means no satellites locked).

Google Maps on receiver tablet isn't updating position

Verify that EXOS GPS Solutions is selected under Android Developer Options → Select mock location app. Toggle Location off and on in Android quick settings.

Permission denied on COM Port

Ensure no other serial software (e.g. PuTTY, Arduino IDE Serial Monitor, OpenCPN) is currently connected to the same COM port. Serial channels allow only one active program at a time.

Frequently Asked Questions

Does EXOS GPS require an active internet connection?

No. Internet access is only needed during initial licence key validation. All GPS telemetry, bridging, mock location, and NMEA log parsing operates 100% offline.

Can I share one phone's GPS with multiple Windows PCs?

Yes! The Android transmitter service accepts connections from multiple receiver clients simultaneously over Bluetooth SPP and Wi-Fi TCP sockets.

What baud rate should I select for USB receivers?

Most standard USB GPS receivers use 9600 baud. High-rate 10Hz receivers may use 38400 or 115200 baud. EXOS auto-detects standard rates.
