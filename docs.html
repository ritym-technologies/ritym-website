Installation Steps

Follow these steps to deploy EXOS GPS on your primary workspace system.

Windows Desktop Client

Download the `.msi` installation package from our Downloads page. Execute the setup package and follow the installation wizard. Ensure you run the application with Administrator rights to allow the mock location controller to interact with the Windows Sensor Framework.

Android Mobile App

Download the raw `.apk` package directly or install it via the Google Play store. To enable the Mock Location feature, go to Android Settings → System → Developer Options, and set EXOS GPS as the mock location application.

Quick Start Guide

Get your telemetry stream active in under 3 minutes.

  1. Start the EXOS GPS client app on your desktop computer or mobile.
  2. Navigate to the Input Settings and choose the interface representing your GPS receiver device (e.g. Serial Port COM3, or Bluetooth paired accessory).
  3. Click the Start Telemetry Stream toggle button to initiate listening.
  4. Inspect the real-time sentence feeds inside the NMEA Monitor log console.

Bluetooth Setup

EXOS GPS supports Bluetooth Classic SPP profiles and Bluetooth Low Energy (BLE) services.

Bluetooth Classic

Pair your external Bluetooth GNSS device inside your OS system settings. Once paired, open EXOS GPS, select "Bluetooth Classic", choose the paired hardware name from the dropdown list, and open the connection channel.

USB Serial Configuration

To connect a USB GPS mouse receiver:

  • Plug the receiver device into an available USB port.
  • Verify the assigned COM Port ID inside the Device Manager dashboard.
  • Select the matching COM Port and configure the baud rate (usually 9600 or 4800) in EXOS GPS.

WiFi Network Forwarding

Transmit location data records across local network interfaces using TCP or UDP sockets.

Configure the target device IP address and socket port inside the EXOS Client network forwarding panel. Ensure your network firewalls allow traffic on the selected port (default is port 5555).

Frequently Asked Questions

Can I use a single license key on multiple machines?

Each Lifetime License purchase activates one physical hardware machine or developer station. You can release and re-associate licenses inside the customer portal.

Does EXOS GPS require active internet access to run?

No. Internet access is only required during initial license validation. Telemetry parsing, local bridges, and GPX playback functions operate completely offline.

Troubleshooting Guide

No NMEA coordinates visible in logs

Ensure the GPS device has a clear line of sight to the sky. Receivers placed indoors might not lock onto satellites (meaning no valid GGA coordinates are broadcast).

COM Port permission errors

Verify that no other GPS viewer software or serial console client is currently connected to that COM port. Serial channels allow only one active client connection at a time.
