4. Wear OS Health & Sensor Data Compliance

For Exos Watchout (exos.ritym.watchout.watchface and exos.ritym.watchout):

  • Heart rate telemetry collected via BODY_SENSORS is strictly utilized for immediate visual rendering on the active dial complication.
  • Exos Watchout does not maintain a historical health database, does not sync biometric data to Google Fit or Health Connect, and does not transmit biometric telemetry over any network interface.
  • Ambient Always-On Display (AOD) adheres strictly to Google's Watch Face Format (WFF v1) specifications, maintaining an On-Pixel Ratio (OPR) below 2.5% with zero background battery drain.

5. Microsoft Windows Desktop & Serial Bridge Policy

For the EXOS GPS Windows Client and Virtual COM Sensor Provider:

  • The Windows desktop client operates purely as a local communications bridge between Bluetooth serial COM ports and the Windows Location Sensor Provider API.
  • The desktop software does not collect diagnostic crash logs, telemetry metrics, or machine identifiers.
  • Zero network sockets are opened to external internet hosts.

7. Zero Third-Party Analytics, Advertising & Data Brokers

Our applications contain:

  • ZERO Analytics Trackers: We do not bundle Google Analytics for Firebase, Mixpanel, AppsFlyer, Facebook SDK, or Flurry.
  • ZERO Data Monetization: We do not sell, rent, license, or trade user location data, device identifiers, or sensor telemetry to data brokers or commercial entities under any circumstances.

8. User Rights, Data Retention & Deletion Instructions

Because all data generated by our applications (such as saved waypoint markers and trail backtrack history) resides exclusively in local on-device SQLite databases, you maintain complete data autonomy:

  • Immediate Data Deletion: You can purge all stored waypoints and trek logs at any time from within the application settings by tapping Clear Local Database.
  • Application Uninstall: Uninstalling the application immediately and permanently removes all application databases and configuration files stored in Android private app storage.
  • No Account Deletion Delay: Because our applications require no user account registration, no remote personal records exist on any cloud server to request deletion for.

9. Child Safety & COPPA / GDPR-K Compliance

Our applications are designed for general outdoor exploration, navigational assistance, and amateur radio telemetry. We do not knowingly collect, solicit, or maintain personal information from children under the age of 13 (or under 16 in the European Union), in full compliance with COPPA and GDPR-K regulations.
