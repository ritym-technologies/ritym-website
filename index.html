EXOS-Station ESP32-S3 GNSS Receiver

Compact high-precision satellite telemetry receiver pairing the Seeed XIAO ESP32-S3 dual-core microcontroller with the u-blox NEO-M9N GNSS engine. Broadcasts raw NMEA sentences across concurrent Wi-Fi AP and authenticated BLE channels.

  • •
    Core Processor: ESP32-S3 Dual-Core Xtensa LX7 @ 240MHz with hardware cryptographic acceleration.
  • •
    GNSS Engine: u-blox NEO-M9N receiving GPS, GLONASS, Galileo, and BeiDou concurrently at 25Hz.
  • •
    Multi-Channel Distribution: Dedicated Wi-Fi AP (EXOS-GPS-XXXXX-WIFI) and authenticated Bluetooth LE (EXOS-GPS-XXXXX-BT).
  • •
    Embedded Web Server & Sockets: On-device configuration portal and real-time JSON API at 192.168.4.1; raw TCP NMEA stream on port 2000.
  • •
    Hardware Security: BLE LE Secure Connections with MITM protection and dynamic 6-digit pairing PIN.

Firmware Engineering

Deterministic FreeRTOS & Network Stacks

Our embedded firmware is built in C++ using PlatformIO and ESP-IDF, leveraging FreeRTOS preemptive multitasking to ensure zero dropped satellite sentences.

Non-Blocking Architecture & Bounded Queues

The EXOS-Station firmware isolates the high-speed UART GPS ingress task on Core 0 from the Wi-Fi/BLE network distribution task on Core 1. A bounded ring buffer ensures that slow or disconnecting wireless clients cannot cause backpressure or buffer bloat on the raw GNSS stream.

  • ✓ Dedicated Core Pinning: UART DMA interrupt servicing pinned to Core 0; network sockets pinned to Core 1.
  • ✓ Authenticated BLE Pairing: LE Secure Connections with MITM protection and numeric comparison.
  • ✓ Local JSON Telemetry API: Real-time satellite constellation metadata exposed over REST at http://192.168.4.1/api/telemetry.
  • ✓ Password-Protected OTA: Over-The-Air firmware updates protected by cryptographic authentication.
